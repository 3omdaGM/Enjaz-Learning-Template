# قالب إنجاز لبيئات التعلم

قالب عربي مستقل لعرض شكل بيئة تعليمية ورحلتها على العملاء. الأسماء والعناوين والمحتوى والأسئلة والوسائط بدائل توضيحية، دون بيانات دراسة أو صور أشخاص أو شعارات جهات حقيقية.

## التشغيل

```bash
npm ci
npm run dev
```

Node.js 22.22 أو أحدث. لبناء نسخة العرض: `npm run build:demo` ثم `npm run preview`.

## تجربة الرحلة

1. افتح تسجيل الدخول: البريد `demo@example.com` والرمز المعلن `DEMO`. التسجيل يسمح باسم مستعار فقط؛ لا تدخل بيانات حقيقية.
2. سلّم القبلي بلا إجابات لتجربة التأهل. القبلي 6 أسئلة توضيحية، وأول نتيجة 50% فأقل تتيح المسار.
3. نفذ نموذج الرسم: 25 شكلًا مصطنعًا، منها 7 للتدريب ثم 9 ثم 9. رسم صحيح واحد على الأقل وأقل من 18 في القسمين المحتسبين يتيح توزيعًا توضيحيًا؛ الصفر يعيد المحاولة و18 يتطلب المراجعة. لتجربة سريعة ارسم المستطيل صحيحًا في أول سؤال محتسب، ورسومًا صغيرة غير مطابقة في البقية. الأشكال والحدود لعرض الآلية، ولا تمثل أداة قياس بحثية.
4. اختر الموديول ثم الدرس، وجرّب الأهداف والمحتوى والنشاط والدعم الثابت/المرن. الحفظ محلي فقط.
5. البعدي 6 أسئلة؛ يحتاج 5 إجابات للتسليم اليدوي. البديل الأول في كل سؤال هو الصحيح في نموذج العرض. لا قيمة بحثية للنتائج.

المدة الافتراضية للقبلي/البعدي 90 دقيقة كما في هيكل العرض. شروط التأهل والتوزيع والمدة توضيحية، ويجب تحديدها وفق دراسة كل عميل.

في نسخة demo فقط يمكن فتح `/demo-tools` لاختيار حالات عرض المجموعات الأربع أو إعادة بدء تجربة بعد تأكيد الاستبدال. البناء العادي يستبعد هذه الصفحة.

## التخصيص

- `src/template/content.json`: عنوان البيئة ومقدمتها، الباحث والمشرفون، الأهداف، الموديولات والدروس، والأسئلة والبدائل.
- `src/course/study.json`: شرح أنماط الدعم والتعلم.
- `src/course/embedded-figures.ts`: هندسة مصطنعة لتوضيح الرسم؛ يجب استبدالها بأداة قياس مناسبة ومصرح بها عند بناء دراسة فعلية.
- `src/template/template.css`: مواضع الشعارات والوسائط البديلة. الألوان والمسافات العامة في ملفات CSS الرئيسية.
- استبدل مواضع الشعارات والفيديو والصور بمحتوى مصرح به في نسخة العميل فقط؛ لا تنقل محتوى عميل إلى هذا القالب.

## GitHub وVercel

هذا المشروع له تاريخ Git جديد؛ لا تستورد تاريخ مشروع سابق. ارفع الملفات إلى مستودع جديد فارغ، ثم اربطه بمشروع Vercel جديد مستقل. يحتوي `vercel.json` على إعدادات البناء وتوجيه الروابط الداخلية. لا تربطه بمشروع استضافة عميل قائم.

التخزين تحت مفاتيح `enjaz-template-session:v1` و`enjaz-template-course:v1`، دون قراءة أو ترحيل مفاتيح مشاريع أخرى. الدخول محاكاة محلية وليس مصادقة خادم. الخط والمكتبات تحت تراخيصها المرفقة؛ لا يحتوي القالب على أصول دراسة خارجية.
